# План: подготовка к публикации drvladt.com

## Уже сделано (проверено по нашим разговорам)

- Анкеты на RU/EN/FR с полями связи, согласиями и серверной выдачей Patient ID (DV…)
- Восстановление кода обращения и повторный ввод кода → переход к загрузке документов
- Кнопка продолжения активируется только после фактической отправки Google Form; примеры кодов убраны из полей
- Загрузка документов в Google Drive (папки по кодам пациентов), независимо от Lovable
- Белый список типов файлов: только PDF, JPG, PNG, HEIC — проверка в окне выбора, на странице и на сервере (по содержимому файла)
- Полный аудит: 33 страницы на трёх языках отдают 200 OK, битых ссылок нет, консоль чистая, 9 YouTube-видео публичные
- Бесшовные переходы на главной, ссылки на юрдокументы вынесены из зоны галочек, плавная прокрутка
- Автоопределение языка: сохранённый выбор → язык устройства → английский по умолчанию
- SEO в коде: уникальные title/description на трёх языках, robots.txt, sitemap.xml (боевой адрес https://drvladt.com уже прописан), микроразметка Schema.org
- Суббренд «Integrative Medicine & Hypnotherapy» в шапке на всех страницах
- GitHub синхронизирован, сборка чистая

## Осталось перед запуском

1. **Опубликовать сайт** (кнопка Publish) и **подключить домен drvladt.com** с переадресацией с www — делается в настройках проекта, требует ваших действий у регистратора домена (DNS-записи)
2. **Проверка вживую после подключения домена:**
   - открыть https://drvladt.com/robots.txt и /sitemap.xml — должны открываться без ошибок
   - проверить замочек HTTPS и редирект www.drvladt.com → drvladt.com
   - сделать контрольную отправку анкеты именно с drvladt.com (разрешение для этого адреса уже настроено на вашем сервере)
3. **Регистрация в поисковых панелях** (после публикации, ~15 минут):
   - Google Search Console — подтверждение через DNS, отправка sitemap.xml
   - Bing Webmaster Tools (важно для ChatGPT Search)
   - Яндекс Вебмастер — по желанию

## Отложено по вашему решению (не блокирует запуск)

- После подключения домена я проведу финальный прогон всех страниц с боевого адреса
