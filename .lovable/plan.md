# Убрать пример кода (DV000123 / DV000001) из всех полей ввода кода

## Зачем
Пример кода в поле-подсказке (placeholder) и в текстах ошибок подсказывает формат кода постороннему человеку. Убираем примеры везде, оставляя пустое поле ввода и нейтральные тексты ошибок.

## Что меняется

1. **Поле «У меня уже есть код» (анкета, все языки)** — `src/components/site-pages.tsx`
   - Убрать `placeholder="DV000123"` у поля ввода кода — поле становится пустым.
   - В тексте ошибки при неверном коде убрать пример (сейчас: «…должен выглядеть как DV000123») на всех трёх языках:
     - RU: «Проверьте код: он введён неверно.»
     - EN: "Please check the code: it doesn't look right."
     - FR: «Vérifiez le code : il semble incorrect.»

2. **Поле кода на странице документов** — `src/components/site-pages.tsx`
   - Убрать `placeholder={page.restorePlaceholder}` — поле пустое.
   - Строку ошибки, которая сейчас выводит «Код обращения: DV000001» (пример из контента), заменить на нейтральный текст ошибки без примера кода.

3. **Контент сайта** — `src/content/site.ru.ts`, `site.en.ts`, `site.fr.ts`
   - Удалить ставшие ненужными значения `restorePlaceholder: "DV000001"` из всех трёх языковых файлов.

## Что не меняется
- Логика проверки и нормализации кода (20 → DV000020) остаётся как есть.
- Сам формат кода DV + 6 цифр не меняется; меняются только подсказки на экране.

## Проверка
- Открыть страницу анкеты и страницу документов на RU/EN/FR: поля ввода кода пустые, без примера.
- Ввести неверный код — текст ошибки без примера кода.
- Ввести корректный код (например, DV000020) — всё по-прежнему работает, автоскролл к анкете сохранён.
