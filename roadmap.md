# Roadmap — сайт Dr Vlad

## Стратегия и основа
- [x] Базовые стратегические решения (языки, адреса, слой контента, стек)
- [x] Три языковых раздела: /ru, /en, /fr + переключатель языка
- [x] Тексты в слое контента (по языкам), отдельно от оформления
- [x] Общий каркас внутренних страниц (шапка, меню, хлебные крошки, подвал)
- [x] Локализованная страница 404

## Контент
- [x] Главная RU / EN / FR (воронка)
- [x] Уплотнён вертикальный ритм главной страницы
- [x] Страницы: Мой подход, Обо мне, Гипнотерапия, Исследовательская работа, Истории пациентов (пустой раздел), Как проходит консультация, Контакты — созданы на трёх языках
- [ ] Наполнить эти страницы полным текстом (сейчас краткая версия с пометкой «текст готовится») — блокер: материалы от Dr Vlad
- [x] Юридические страницы (политика конфиденциальности, условия использования, медицинский дисклеймер, предупреждение для экстренных ситуаций) — черновики
- [ ] Юридическая проверка и финальные формулировки — блокер: решение Dr Vlad

## Путь обращения
- [x] Кнопка «Хочу разобрать мой случай» ведёт на страницу консультации
- [x] Три обязательных подтверждения + кнопка «Продолжить к анкете» (неактивна до подтверждений)
- [x] Код обращения и защищённая сессия создаются только после согласий (пока локально, демо)
- [x] /ru/anketa, /ru/dokumenty, /ru/spasibo и EN/FR-аналоги, защита пути без согласий
- [x] Восстановление потерянной сессии загрузки по коду обращения
- [ ] Подключить реальную анкету и защищённое хранилище документов — блокер: юридическая проверка и ссылка на форму

## Отложено / заблокировано
